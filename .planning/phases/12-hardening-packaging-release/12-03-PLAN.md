## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| secret store -> logs/errors | A model credential must never cross from the store into any rendered output |
| secret store -> child argv | A credential must never cross into a command line visible in task manager |
| child process -> supervisor stdio | Untrusted bytes from PG/TEI/Python cross into the log pipeline |
| user machine -> product I/O | Long and non-ASCII paths cross into every file operation |
