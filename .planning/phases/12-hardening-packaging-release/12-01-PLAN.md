<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build machine -> installer | Untrusted staging inputs (downloaded zonky/pgvector/llama artifacts) cross into the shipped bundle |
| installer -> user machine | NSIS writes sidecar binaries the app later executes |
| app -> sidecar processes | The supervisor spawns long-lived child processes that survive app bugs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Tampering | resource staging (assemble-resources) | high | mitigate | Every staged file is covered by resources/MANIFEST.sha256 written at build; layout test re-verifies hashes on disk before electron-builder packs; a mismatch fails `just build`. |
| T-12-02 | Elevation | NSIS installer | high | mitigate | Per-user install to %LOCALAPPDATA%\HALO without elevation (PostgreSQL refuses elevated execution); the install-launch test runs the installer non-elevated and asserts success; the supervisor's elevated-parent refusal lands in 12-02. |
| T-12-03 | Information Disclosure | child env inheritance | medium | mitigate | Sidecar spawns use an explicit env allowlist (per AGENTS.md section 4 settings table) — a developer's PGPORT/HF_HOME never reaches a child; the allowlist is asserted in the layout test. |
| T-12-04 | Denial of Service | orphaned sidecar processes | high | mitigate | Every child is assigned to a KILL_ON_JOB_CLOSE Job Object held by the supervisor; the install-launch test asserts zero surviving PIDs after a force-kill. |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages in this phase: `bun install --frozen-lockfile`, `cargo build --locked`, `uv sync --locked` only; every installed artifact comes from the Phase 1-11 locked lockfiles. |
</threat_model>
