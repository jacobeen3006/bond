## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| supervisor → bundled PG cluster | The supervisor owns the cluster lifecycle; an unauthenticated or externally-reachable DB is the primary exposure |
| supervisor → llama-server sidecars | Loopback inference endpoints; an unkeyed or non-loopback sidecar is reachable by any local process |
| supervisor → hindsight-api child | The child inherits the env block (DB URL, API keys); a leaked env value is a credential leak |
| first-run model download → GGUF bytes | A runtime download without a digest pin is a supply-chain surface |
