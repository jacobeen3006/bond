## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| supervisor → hindsight-api child | The child inherits the env block (DB URL, API keys); a leaked env value is a credential leak; a second queue consumer double-claims |
| `async_operations` queue → retain | A lost or double-applied retain is the user-data-loss failure the MEM-06 gate closes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-04 | Denial of Service | `hindsight.ts` env block + degraded mode | medium | mitigate | The per-op LLM env config is explicit (`HINDSIGHT_API_LLM_PROVIDER=none` degraded default: chunk-store + rrf failover); `HINDSIGHT_API_LLM_MAX_CONCURRENT=4` bounds concurrency; the `litellm` wire format is the only compatible one (a `tei` wiring 404s and fails the boot, caught by `hindsight-embed.test.ts`); the supervisor spawns ONE `hindsight-api` child (in-process `WorkerPoller`), never a second queue consumer |
