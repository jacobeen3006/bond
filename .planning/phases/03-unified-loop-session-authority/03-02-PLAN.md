<objective>
Make the single-store promise enforceable across processes: one owner writes, every other process reads, and a store that cannot honour WAL or HALO's schema is refused before a byte is written.

**User story (MVP enrichment):** **As a** developer running HALO, **I want to** be unable to start a second writer or accidentally point the transcript at a network share, **so that** my only copy of the conversation is never silently forked or corrupted.

Purpose: LOOP-02 is only true if ownership is a property of the store, not a convention in the daemon. This plan turns "one writer" and "local path" into typed refusals with executable proof.
Output: `state/epoch.py`, an open policy inside `SessionStore`, and multi-process tests that fail if a second writer or a remote path is ever accepted.
</objective>
