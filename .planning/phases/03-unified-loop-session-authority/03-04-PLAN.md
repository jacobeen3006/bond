<objective>
Make "the turn is finished" a fact the store can prove: one predicate, one close writer, and database triggers that make a premature close, a reopen, or an append after close impossible.

**User story (MVP enrichment):** **As a** developer, **I want to** see a turn marked complete only when the model has actually finished and no background work is still attached to it, **so that** a later tool result can never be appended to an answer that was already presented as final.

Purpose: LOOP-06 is the difference between a chat log and a truthful lifecycle. The predicate must live in one function and be enforced in two layers (code and DDL), because a UI that goes quiet is not evidence of completion.
Output: `loop/turn.py` with the predicate, the close writer and the Pydantic close record, plus a variant-matrix test and trigger-abort tests.
</objective>
