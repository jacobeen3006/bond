<objective>
Turn the phase's invariants into a regression corpus: twelve golden sessions that replay the real loop against a scripted provider and assert the store's post-conditions, run by one deterministic command that CI gates on.

**User story (MVP enrichment):** **As a** HALO maintainer, **I want to** re-run every known failure mode — interrupt, crash, compaction, steer, redaction — as a deterministic fixture, **so that** a regression in the loop is caught by CI rather than by a user losing a session.

Purpose: the AI-SPEC makes the deterministic lane the phase gate and the judge lane on-demand; this plan supplies both substrates without introducing a server, Docker or telemetry.
Output: the ledger format, 12 fixtures, the replay harness, `just eval`, the on-demand judge, and the CI job.

**PATTERNS.md analog per new file (03-PATTERNS.md File Classification):** `tests/evals/ledger/*.jsonl` and `tests/evals/ledger/schema.md` -> Phase 1/2 fixture-tree builders (`01-08-PLAN.md:99,126`; `02-06-PLAN.md:105`, `partial-planned`); `tests/evals/replay.py` -> no precedent (`none`; the harness is new, and it follows the fixture-isolation discipline of `02-06-PLAN.md:105`); `tests/evals/test_ledger.py` -> named-case/literal-token discipline (`01-08-PLAN.md:131,144`, `partial-planned`); `halo_agent/evals/__init__.py` -> package marker (`none`, same shape as `halo_agent/loop/__init__.py`); `halo_agent/evals/judge.py` -> no precedent, explicitly excluded from `just eval` (`03-AI-SPEC.md:457-480`, `none`); `tests/evals/judge-set.jsonl` and `tests/evals/calibration.jsonl` -> Phase 1/2 fixture-tree builders (`partial-planned`); `justfile` -> `01-09-PLAN.md:90`, `01-01-PLAN.md:243-247`, `STACK.md:55-85` (`exact-planned`); `.github/workflows/ci.yml` -> `01-09-PLAN.md:150-162`, `02-08-PLAN.md:126` (`exact-planned`). No file uses a pattern outside this list.

**File-count trade-off (recorded):** 20 declared files, of which 14 are fixtures (12 ledger cases + the 5-case judge seed + the 20-case calibration file, with `schema.md` counted separately) and only five are code (`replay.py`, `test_ledger.py`, `judge.py`, `__init__.py`, CI). Fixture expansion is data volume, not reasoning volume: each ledger case is a small JSONL file whose expectations are already specified by the plan it mirrors.
