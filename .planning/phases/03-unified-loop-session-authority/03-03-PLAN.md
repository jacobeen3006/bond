<objective>
Make queue, follow-up and steer crash-safe by giving every input a durable admission record before anything else happens, and make crash recovery deterministic: a dead-owner turn resolves to `unknown` and its side effects are never replayed.

**User story (MVP enrichment):** **As a** developer whose daemon crashes mid-turn, **I want to** come back to a session that either contains the turn's effects or explicitly asks me about the one that was interrupted, **so that** no shell command or file edit silently runs twice.

Purpose: LOOP-01's queue/steer/follow-up semantics and LOOP-02's durability both bottom out in this FIFO. Without it, an input can vanish on a crash and a side effect can be replayed after one.
Output: the admission state machine, the recovery transaction, FTS audit/repair, and a killed-child fixture proving `unknown` is never replayed.
</objective>
