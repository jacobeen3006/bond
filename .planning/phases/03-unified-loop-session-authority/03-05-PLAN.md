<objective>
Make "the transcript is what the model received" checkable rather than aspirational: one builder produces the only object a provider can accept, the exact bytes are recorded at the HTTP layer in tests, and every position is proven against a stored hash.

**User story (MVP enrichment):** **As a** developer debugging "the model ignored my correction", **I want to** diff the visible transcript against the bytes actually sent for every turn, **so that** injected context, compaction summaries and ephemeral warnings can never be invisible.

Purpose: LOOP-05 fails silently — both sides look individually correct. The mechanism that makes it structural is the single builder plus per-position hashes plus HTTP-level recording.
Output: `RequestPayload`/`RequestBuilder`, `ProviderTransport`, a byte-recording mock server, and mirror tests including a >2 MiB turn.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| loop -> provider HTTP | The only place bytes leave the process for a model |
| test recorder -> assertions | Recorded bodies are the evidence for the mirror invariant |
| DB text columns -> hash | Unencodable text would make a stored hash describe bytes that cannot exist |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-05 | Repudiation | `loop/request.py`, `provider/transport.py` | high | mitigate | Single builder is the only producer of `RequestPayload`; manifest persisted in the same transaction; strict dev check blocks and records `mirror_diff`; HTTP-level recording in tests. |
| T-3-11 | Tampering | `canonical_bytes`, `scrub_text` | low | mitigate | Scrub before hash and persist; one canonical serialization function; lone-surrogate test. |
| T-3-12 | Denial of Service | oversize bodies / recorder | medium | mitigate | Bodies are read as documents with `Content-Length` equality; bodies are never written to JSONL events; the 2 MiB fixture pins the size path. |
| T-3-SC | Tampering | dependency installs | high | mitigate | No new package; standard library only for JSON, hashing and HTTP test server. |
</threat_model>
