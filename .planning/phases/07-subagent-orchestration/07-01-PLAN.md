<objective>
Prove the phase's architecture end to end on the first slice: one `task` call creates a child session with a one-time gate copy, the child runs one governed turn through the same loop with `agent_kind='sub'`, and a typed result returns to the parent — with a denied child call proven to have touched nothing.

**User story (MVP enrichment):** **As a** HALO user, **I want to** delegate a bounded task to a subagent that is governed by my policy and returns a typed result, **so that** I can parallelize work without losing governance or accounting.

The ROADMAP Phase 7 goal ("HALO can spawn, govern, control, and account for subagent sessions") is outcome-shaped, not a user story; the sentence above restates it faithfully and adds no scope.

Purpose: this is the tracer. It wires every core layer Phase 7 touches — the `task` tool handler, the child session creation with gate inheritance, the child runner driving the same loop, the per-call governance with `agent_kind='sub'`, the typed result, and the `turn_background_work.kind='task'` lifecycle row — in one runnable path, so an architectural dead end (a gate copy that is a live pointer, a child turn that stamps `agent_kind='main'`, a typed result that loses the child's `session_id`, a background-work row that never transitions) is caught after one commit instead of after three plans. Production quality, kept for good: real error handling on the one path, no stubs, no batch fan-out, nothing that later needs an architectural change.

Output: the `task` entry in `contracts/tool-ownership.json`, `halo_agent/tools/backends/task.py`, `halo_agent/subagent/runner.py`, the store writers for child session creation and gate inheritance, and three green test files (`tests/subagent/test_task_spawn.py`, `test_isolation.py`, `test_child_governance.py`) plus the shared `tests/subagent/conftest.py`.

**Why this plan carries the core path only (recorded trade-off):** the tracer's whole value is that it touches each core layer exactly once — the manifest entry, the tool handler, the child session creation, the gate copy, the child runner, the per-call governance, the typed result, and the background-work row. Splitting them commits a gate copy no test proved is a one-time copy, a child runner no test proved stamps `agent_kind='sub'`, or a typed result no test proved carries the child's `session_id`. Only `store.py` and the two new modules carry real logic; the control (SUB-03) and the pool/cost (SUB-04) layers are expansion tasks in plans 02 and 03.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| parent session -> child session | The parent's `task` tool call spawns a child session; the child's tool calls are model-produced and untrusted |
| child session -> gate | The child's tool calls are judged by the gate; the child's gate is a one-time copy of the parent's gate |
| any writer -> `tool_invocations` | A state transition to `dispatched` is the "side effect may exist" promise crash recovery relies on |
| child session -> parent workspace | The child's `read`/`write` tools may reach the parent's workspace unless isolation is configured |

## STRIDE Threat Register

Threat IDs unique in phase; this plan opens the register at T-07-01.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering | ungoverned child dispatch (a child tool call without a policy decision) | high | mitigate | The Phase 4 `tool_invocations_dispatch_guard` trigger refuses `state='dispatched'` with a NULL decision id by the literal `ungoverned_dispatch` abort; the child's loop stamps `agent_kind='sub'` and evaluates by the child's own `PolicySnapshot`; `test_child_governance.py` asserts a denied child call is never `dispatched`. |
| T-07-02 | Elevation | a child session escaping its gate (a child with a more permissive gate than the parent) | high | mitigate | Gate inheritance is a one-time copy of the parent's `session_gate_state`; the child cannot have a more permissive gate than the parent; `test_child_governance.py` asserts the child's gate equals the parent's gate at creation and is not a live pointer (mutating the parent's gate after child creation does not change the child's gate). |
| T-07-03 | Information Disclosure | a child session accessing the parent's secrets or other sessions' data | medium | mitigate | Configurable isolation; the child's workspace roots are scoped to the child; `test_isolation.py` asserts the child cannot read the parent's workspace when `allow_parent_read=False`. |
| T-07-SC | Tampering | package installs (`uv sync`) | low | accept | Phase 7 installs no new package; `uv.lock` is byte-unchanged. Any future install needs a fresh legitimacy audit plus a blocking-human checkpoint. |
</threat_model>
