## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| HALO adapter -> core child process | Untrusted process boundary; the core is a supervised child, not in-process |
| ready frame -> adapter | The `contractHash`/`contractVersion` cross here; a tampered core could present a wrong hash |
| tool args -> core handler | A `cwd` or `args` path crosses here; a disallowed tool name crosses here |
