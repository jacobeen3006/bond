<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scheduler→Hindsight op store | The scheduler flips an operation to `cancelled`; Hindsight detects it at its next `_check_op_alive` boundary. Untrusted: a preemption must not corrupt memory state. |
| L1 lease→deadline | A recall crosses the 10 s deadline; the degraded fallback must be a visible signal, not a silent one. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-9-03 | Tampering | `Lease` preemption trigger | high | mitigate | Cooperative boundary-aligned cancellation (Hindsight `_check_op_alive`); never hard-cancel; `status <> 'cancelled'` guards on all terminal writes; `preemption_only_at_operation_boundary` + `cancelled_writes_never_commit` tests. |
| T-9-04 | Tampering | requeue ownership | high | mitigate | Scheduler only triggers cancellation; Hindsight reconcile sweep owns requeue (single owner); `reconcile_sweep_rediscovers` test; no scheduler-side requeue queue. |
| T-9-06 | Denial of Service | `Deadline` L1 fallback | medium | mitigate | Visible `degraded: true` flag (P-4); per-turn token prevents unbounded same-turn retries; `deadline_fires_degrades` + `no_same_turn_retry` tests. |
</threat_model>
