<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI -> daemon session store | The CLI only sends RPC commands; it must not write the store directly. |
| daemon -> multiple surfaces | Event frames are multicast; one surface's frames must not leak another surface's request/response. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-04 | Elevation of Privilege | CLI session store access | high | mitigate | Enforce single-writer store (Phase 3): surfaces only issue RPC commands; a test asserts the CLI cannot write the store directly. |
| T-10-05 | Information Disclosure | broadcast.py | medium | mitigate | Multicast event frames only; request/response stays id-correlated 1:1 so one surface cannot read another surface's private responses. |
| T-10-06 | Denial of Service | broadcast fan-out | medium | mitigate | Bound the subscriber registry and per-connection outbound queue; drop-with-notification (never silent drop) when a subscriber falls behind. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages in this plan (Bun ws client and Python stdlib only); plan 01's websockets checkpoint still gates the transport dependency. |
