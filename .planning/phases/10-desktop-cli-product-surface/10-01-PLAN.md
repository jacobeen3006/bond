<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| surface client -> daemon WS | Untrusted client attaches to the loopback daemon over WS; frames are untrusted input. |
| daemon WS -> network | The daemon must not bind any external interface; only 127.0.0.1 is trusted. |
| frame payload -> protocol | Oversized / malformed frames must be rejected, not accepted and executed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01 | Elevation of Privilege | ws_server.py bind | high | mitigate | Bind to 127.0.0.1 only; test asserts no 0.0.0.0 / external interface is reachable. |
| T-10-02 | Denial of Service | ws_server.py frame handling | medium | mitigate | Enforce maxFrameBytes 1048576 / maxReassembledFrameBytes 67108864; reject oversized or malformed frames rather than buffering them. |
| T-10-03 | Spoofing | id correlation | medium | mitigate | Correlate request/response strictly by `id`; reject or drop uncorrelated frames so one surface cannot observe another's responses. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate: blocking human checkpoint before `uv add websockets` (Task 2); verify at pypi.org/project/websockets and github.com/python-websockets/websockets. |
</threat_model>
