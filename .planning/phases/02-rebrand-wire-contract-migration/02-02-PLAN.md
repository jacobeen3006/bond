## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| contract file → three-language codecs | One JSON decides the wire vocabulary of both processes; a forged or drifted entry splits the protocol permanently |
| canonical serialization → hash | The hash is the handshake's integrity anchor; canonical-form drift between languages is a permanent mismatch (or worse, a collision of trust) |
| vendored rpc-types.ts → census | Source-derived reconciliation reads untrusted-at-import code; parse bugs silently rewrite the contract |
