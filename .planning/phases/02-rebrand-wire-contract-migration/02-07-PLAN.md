## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user plugin config → loader | Enabled ids are user-authored data consumed by renamed loader code; vocabulary drift between them silently disables features |
| legacy entry-point group → discovery | Third-party plugins register under the old group; dropping it orphans them; keeping it forever keeps two vocabularies (alias-window class) |
| plugin packages → process | Plugins execute in-process; a rebrand that mis-resolves a plugin id could load an unintended package claiming the old name |
